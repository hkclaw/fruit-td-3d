# 水果塔防傳奇 3D (Fruit Tower Defense 3D)

單檔 Three.js 3D 水果塔防。在蜿蜒路徑旁放置 12 種水果塔，抵擋 20 波腐敗水果大軍。

## 如何開啟

1. Clone 本倉庫，或下載 `index.html`
2. 用瀏覽器直接開啟 `index.html`（建議 Chrome / Edge / Firefox）
3. 或起靜態伺服器：
   ```bash
   python3 -m http.server 8080
   # 造訪 http://localhost:8080
   ```

無需建置；GitHub Pages / 任意靜態託管皆可。

## 操作

| 操作 | 說明 |
|------|------|
| 開始遊戲 | 標題畫面按「開始遊戲」 |
| 放置塔 | 底部塔列點選 → 點地圖空地（不可壓路徑）。放置中會鎖定旋轉，拖曳超過數像素不放置，點 HUD 不會建塔 |
| 升級 / 出售 | 點已建塔 → 右側 **攻擊力 A** / **射速+射程 B** / 出售（退約 60%） |
| 開始波次 | 右側 ▶；波次進行中再按可 **提前出兵** 並領剩餘生成獎勵 |
| 速度 | 右側 ⏩ 切換 1x / 2x（快捷鍵 `1` / `2`） |
| 視角 | 未選塔時拖曳旋轉、滾輪縮放；相機按鈕重置 |
| 取消 | `Esc` |

## 12 種水果塔

| 塔 | 特色 |
|----|------|
| 蘋果塔 | 均衡傷害 / 射速 |
| 香蕉塔 | 迴旋鏢（飛出再飛回）+ 擊退 knockback |
| 西瓜塔 | 範圍濺射 splash |
| 草莓塔 | 超高射速 |
| 鳳梨塔 | 穿透 pierce |
| 葡萄塔 | 擊中分裂 split |
| 檸檬塔 | 永久破甲 armor shred |
| 椰子塔 | 暈眩 stun |
| 芒果塔 | 遠程狙擊 |
| 藍莓塔 | 毒素 DoT poison |
| 火龍果塔 | 燃燒地面 burn zone |
| 奇異果塔 | 減速 slow |

升級：分支 **A** 提升傷害（約 ×1.4 / 級），分支 **B** 提升射速與射程；升級後塔體會放大，並加上金色（A）／青色（B）層環與底座光暈。

## 敵人與波次

≥8 種敵人：腐爛蘋果、發霉香蕉（死亡分裂）、腐爛西瓜（死亡爆炸）、果蠅（飛行）、鐵石榴（高護甲）、尖刺黃瓜、毒茄子、**巨型南瓜王**（Boss）。

明確 **20 波**表，難度遞增；**第 10、20 波**出現 Boss。中毒／燃燒／減速／暈眩／破甲有獨立光環提示。

## 技術

- Three.js r128（CDN）+ OrbitControls
- 程序化草地／泥土貼圖、指數霧、主光 + 補光 + 輪廓光、PCF 軟陰影、接觸斑影
- 粒子／衝擊閃光／濺射環使用物件池，幾何與材質盡量共用
- Tailwind CDN、Font Awesome
- 高對比玻璃擬態 HUD
- 純前端單檔，類別：`Tower` / `Enemy` / `Projectile` / `BurnZone` / `Game`

## 已知限制（誠實）

- 美術仍是程序化 primitive（球／錐／柱／管），不是精細手作模型；辨識度靠剪影與配色，不是寫實材質
- 無音效 / 音樂
- 路徑禁建為距離近似，非精確碰撞網格
- 接觸陰影是貼地圓斑，不是螢幕空間 contact shadow
- 類別 API 部分為包裝既有函式式戰鬥迴圈，便於擴充與除錯
- 數值為初版平衡，未完整 playtest
- 大量敵人 + 穿透／分裂時低階裝置可能掉幀（建議 1x）
- 需 WebGL；選塔放置時旋轉鎖定，未選塔時拖曳旋轉仍可能誤選已建塔（點擊未拖曳才會選取）
