# 水果塔防傳奇 3D (Fruit Tower Defense 3D)

單檔 Three.js 3D 水果塔防遊戲。在蜿蜒路徑上放置水果塔，抵擋 20 波害蟲大軍。

## 如何開啟

1. 下載或 clone 本倉庫
2. 用瀏覽器直接開啟 `index.html`（建議 Chrome / Edge / Firefox）
3. 或起一個靜態伺服器後開啟，例如：
   ```bash
   python3 -m http.server 8080
   # 然後造訪 http://localhost:8080
   ```

GitHub Pages / 任意靜態託管亦可，無需建置步驟。

## 操作

- **開始遊戲**：標題畫面按「開始遊戲」
- **選塔放置**：底部水果列點選，再點地圖空地放置（不可壓在路徑上）
- **升級 / 出售**：點已放置的塔 → 右側面板選攻擊分支 A、射程分支 B，或出售（退 60%）
- **下一波**：右側 ▶ 或空白鍵
- **速度**：右側 ⏩ 切換 1x / 2x（或按鍵 `1` / `2`）
- **視角**：滑鼠拖曳旋轉、滾輪縮放；相機按鈕重置
- **取消選取**：`Esc`

## 內容概要

- **12 種水果塔**與真實效果：濺射、穿透、分裂、毒素 DoT、燃燒區域、減速、擊退、暈眩、破甲
- **8+ 種敵人**，20 波表；第 10、20 波有 Boss
- 金錢 / 生命 / 波次 HUD、開始／勝利／失敗玻璃擬態 UI

## 技術

- Three.js r128（CDN）+ OrbitControls
- Tailwind CDN（輔助）、Font Awesome 圖示
- 純前端單檔，無後端、無建置

## 已知限制

- 美術為 primitive 幾何體（球／錐／柱），非精細模型
- 無音效／音樂
- 路徑鄰近不可建塔，判定為近似距離而非精確碰撞網格
- 穿透／分裂在極多敵人時可能較吃效能（低階裝置建議 1x）
- OrbitControls 與點地建塔共用滑鼠；拖曳旋轉時請避免誤點
- 平衡為初版數值，未做完整 playtest 調參
- 需 WebGL；極舊瀏覽器可能無法運行
