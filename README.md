# 水果塔防傳奇 3D (Fruit Tower Defense 3D)

單檔 Three.js 3D 水果塔防。在黃昏維港堤岸的蜿蜒馬路旁放置 12 種水果塔，抵擋 20 波腐敗水果大軍。

GitHub Pages：https://hkclaw.github.io/fruit-td-3d/

## 如何開啟

1. Clone 本倉庫，或下載 `index.html`
2. 用瀏覽器直接開啟 `index.html`（建議 Chrome / Edge / Firefox；手機 Safari / Chrome 亦可）
3. 或起靜態伺服器：
   ```bash
   python3 -m http.server 8080
   # 造訪 http://localhost:8080
   ```

無需建置；GitHub Pages / 任意靜態託管皆可。

## 操作

| 操作 | 桌面 | 手機 / 平板 |
|------|------|-------------|
| 開始遊戲 | 標題畫面按「開始遊戲」 | 同左（大按鈕） |
| 放置塔 | 底部塔列點選 → 點地圖空地（不可壓路徑） | 輕點塔卡 → 輕點空地；拖曳超過閾值不放置 |
| 升級 / 出售 | 點已建塔 → **攻擊力 A** / **射速+射程 B** / 出售（退約 60%） | 同左；窄螢幕改為底部面板，不必靠 hover |
| 開始波次 | 右側 ▶；波次進行中再按可 **提前出兵** 並領剩餘生成獎勵 | 同左；觸控目標 ≥48px |
| 速度 | 右側 ⏩ 切換 1x / 2x（快捷鍵 `1` / `2`） | 同左 |
| 視角 | 未選塔時拖曳旋轉、滾輪縮放；相機按鈕重置（對準抬高後的堤岸） | 單指旋轉、雙指捏合縮放；操作 HUD 時不會轉鏡頭 |
| 取消選擇 | **取消選擇** 按鈕或 `Esc`：清掉建塔類型與已選塔面板 | 大觸控按鈕（選了塔卡或已建塔時才出現） |

放置中會鎖定旋轉；輕點 HUD 不會建塔。手機開始後有可關閉的操作提示。波次進行中頂部會顯示「敵人進攻中」，碼頭有方向箭頭與路徑提示。

## 地圖環境（香港程序化 reskin）

只改場景，不改塔／敵／經濟／波次數值：

- 維港感水面（頂點波浪 + 黃昏／霓虹反射）
- 遠處低面數天際線與山脊剪影
- 路徑是瀝青馬路 + 石屎路緣 + 斑馬線暗示（不是泥徑）
- 黃昏霧、暖冷對比燈光、霓虹條
- 起點：碼頭／天星小輪色塊暗示；終點：IFC 感高樓 + 山峰剪影
- 塔與敵人仍是水果主題
- 堤岸／水面／路徑／地標整體抬高，預設相機與軌道目標對準抬高後的地面（路徑與放置仍用 XZ，不改 canPlace／進度公式）
- 出兵方向：碼頭箭頭＋脈衝，路徑上有進攻提示；HUD 在 `waveActive` 時強調「敵人進攻中」

## 12 種水果塔

| 塔 | 特色 |
|----|------|
| 蘋果塔 | 均衡傷害 / 射速 |
| 香蕉塔 | 迴旋鏢（飛出再飛回）+ 擊退 knockback |
| 西瓜塔 | 範圍濺射 splash |
| 草莓塔 | 超高射速 |
| 鳳梨塔 | 穿透 pierce |
| 葡萄塔 | 擊中分裂 split |
| 檸檬塔 | 永久破甲 armor shred |
| 椰子塔 | 暈眩 stun |
| 芒果塔 | 遠程狙擊 |
| 藍莓塔 | 毒素 DoT poison |
| 火龍果塔 | 燃燒地面 burn zone |
| 奇異果塔 | 減速 slow |

升級：分支 **A** 提升傷害（約 ×1.4 / 級），分支 **B** 提升射速與射程；升級後塔體會放大，並加上金色（A）／青色（B）層環與底座光暈。

## 敵人與波次

≥8 種敵人：腐爛蘋果、發霉香蕉（死亡分裂）、腐爛西瓜（死亡爆炸）、果蠅（飛行）、鐵石榴（高護甲）、尖刺黃瓜、毒茄子、**巨型南瓜王**（Boss）。

明確 **20 波**表，難度遞增；**第 10、20 波**出現 Boss。中毒／燃燒／減速／暈眩／破甲有獨立光環提示。

**傷害（1–3 波）：** 在 `1236749` 已核對為 PASS，不是戰鬥公式 bug。Discovery 先前「沒掉血」是塔放在路徑起點（約 `z≈28`）射程外。本分支未改傷害／護甲公式。

## 技術

- Three.js r128（CDN）+ OrbitControls（單指 ROTATE / 雙指 DOLLY_PAN）
- 程序化維港水面 shader、黃昏天空球、瀝青路帶／石屎人行、指數霧、暖主光 + 冷補光 + 霓虹點光、PCF 軟陰影
- 粒子／衝擊閃光／濺射環使用物件池，幾何與材質盡量共用
- Tailwind CDN、Font Awesome
- 高對比玻璃擬態 HUD；`viewport-fit=cover`、safe-area、100dvh 全螢幕畫布
- 純前端單檔，類別：`Tower` / `Enemy` / `Projectile` / `BurnZone` / `Game`

## 已知限制（誠實）

- 美術仍是程序化 primitive（球／錐／柱／管），不是精細手作模型；辨識度靠剪影與配色，不是寫實材質
- 無音效 / 音樂
- 路徑禁建為距離近似，非精確碰撞網格
- 接觸陰影是貼地圓斑，不是螢幕空間 contact shadow
- 類別 API 部分為包裝既有函式式戰鬥迴圈，便於擴充與除錯
- 數值為初版平衡，未完整 playtest
- 大量敵人 + 穿透／分裂時低階裝置可能掉幀（建議 1x）
- 需 WebGL；輕點未拖曳才會選塔／放置。遠景建築是 hinterland，不參與碰撞
